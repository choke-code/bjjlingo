Dicas para lembrar no treino:

    Aviso importante de treino

    Antes de comecar, leia com atencao:

    1. Aqueça sempre antes de treinar (5-10 min).

    2. Respeite os limites do seu corpo. Diferente não é mais fraco.

    3. Nunca aplique técnicas em ninguém sem supervisão do professor.

    4. Pare imediatamente se sentir dor ou desconforto no pescoço, joelhos ou costas.

    5. Em caso de qualquer problema, consulte um profissional de saúde.

    Login com Google

    Para ativar, cole seu OAuth Client ID no script.js (variavel GOOGLE_CLIENT_ID).

    1. Acesse console.cloud.google.com e crie um projeto.
    2. Crie uma tela de consentimento OAuth (tipo Externo).
    3. Crie um Client ID OAuth tipo "Aplicativo Web".
    4. Adicione a origem autorizada: https://choke-code.github.io.
    5. Copie o Client ID para o script.js e salve.
    6. Abra via servidor local (python -m http.server 8000) ou pelo GitHub Pages.
